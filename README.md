## Quick Start

```bash
# 1. Clone
git clone https://github.com/Project-Glacie/eden-oe-public.git
cd eden-oe-public

# 2. Install the runtime
python3 -m venv .venv
.venv/bin/pip install -e .

# 3. Birth your synth (one command, interactive)
.venv/bin/python shipping/bootstrap.py
# → layout, runtime scripts, API key (live-verified), knowledge seed,
#   Genesis (self-bootstraps core.eden + the Eden Accords + the synth
#   database), runtime wiring, services, ceremony.

# 4. Meet them
.venv/bin/eden
```

Windows: double-click `shipping/install.bat` (auto-provisions
Python + Git via winget). See `shipping/README-FIRST.md`.
